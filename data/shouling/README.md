# 壽陵碑額

The sixteen seal-script characters of the title 大白高國護城聖德至懿皇帝壽陵誌銘, as drawn in
李範文《夏漢字典》 p. 90. The strip was uploaded to Wikimedia Commons by 唐吉訶德的侍從 as
[File:西夏文 大白高國護城聖德至懿皇帝壽陵誌銘.jpg](https://commons.wikimedia.org/wiki/File:%E8%A5%BF%E5%A4%8F%E6%96%87_%E5%A4%A7%E7%99%BD%E9%AB%98%E5%9C%8B%E8%AD%B7%E5%9F%8E%E8%81%96%E5%BE%B7%E8%87%B3%E6%87%BF%E7%9A%87%E5%B8%9D%E5%A3%BD%E9%99%B5%E8%AA%8C%E9%8A%98.jpg),
under **CC BY-SA 4.0**; read 2026-11-07. The file description lists the sixteen characters in the
order of the strip and gives the 夏漢字典 index of each.

`seal-title.jpg` is the unmodified download. `scripts/build_tangut_script_forms.py` cuts it at the
blank columns between the characters and writes one PNG per character to
`app/public/seal/shouling/`, plus `app/data/tangut-script-forms.json`. The crops are derivatives of
the same file and stay under CC BY-SA 4.0.
